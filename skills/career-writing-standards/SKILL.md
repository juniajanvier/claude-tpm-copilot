# Career writing standards

A style guide plus a fact sheet. Every career document starts from verified titles and dates, and ends with a mechanical check.

## Placeholders

| Variable | Meaning |
|---|---|
| `{{OWNER_NAME}}` | Person whose voice the documents use |
| `{{CURRENT_TITLE}}` | Exact current title, e.g. "Senior Data/AI/Risk Product Manager" |
| `{{BANNED_TITLES}}` | Titles that must never be used for the current role |
| `{{ROLE_HISTORY}}` | List of prior roles: org, exact title, month-year range, one-line scope |
| `{{EDUCATION}}` | Degree and school (no graduation year unless the owner wants it) |
| `{{LICENSES}}` | Professional licenses and where they apply |
| `{{FRAMING_POINTS}}` | Two to four public, non-confidential points about current scope |
| `{{PROFILE_MEMORY}}` | Memory files to read for current scope before writing |

## Hard rules (every document)
- No em dashes.
- Never open a sentence with "I".
- Never use: "passionate about", "dedicated to", "spearheading", "at the intersection of".
- American dates: "October 2", never "2 October".
- Consulting contexts: say "equity-centered" or "community-centered", never "DEI".

## Titles and facts
- Current role: **`{{CURRENT_TITLE}}`**. Never `{{BANNED_TITLES}}`.
- Prior roles: `{{ROLE_HISTORY}}`. Use exact titles; never downgrade a real title (for example, a summer program manager role is not "Intern" if the title was Program Manager).
- Education: `{{EDUCATION}}`. Never list the graduation year unless asked.
- Licenses: `{{LICENSES}}`. State the jurisdiction; never imply coverage outside it.
- Read `{{PROFILE_MEMORY}}` for current scope before writing; scope grows fast.

## Current-role framing
- Use only `{{FRAMING_POINTS}}`: public, resume-safe statements of scope, scale and regulatory context.
- Keep OKRs, team names, internal system names and unreleased work out. That is the employer's IP.

## Check before delivering
Search the draft for em dashes, sentences starting with "I", banned phrases, wrong titles, and a graduation year. Fix every hit before handing it back.
